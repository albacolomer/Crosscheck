# Crosscheck

Aplicación de fact checking durante entrevistas, construida con React, TypeScript y Vite.

## Desarrollo

```sh
npm install
npm run dev
```

## Comprobaciones

```sh
npm run lint
npm run build
```

Para previsualizar la compilación: `npm run preview`.

El alcance del proyecto y la propuesta de integración con OpenAI están en [PLAN.md](./PLAN.md).
